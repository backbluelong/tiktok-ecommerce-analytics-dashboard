# TikTok Ecommerce Analytics Dashboard
Ecommerce &amp; Marketing Performance Dashboard using Power BI, SQL and BigQuery
## 📌 Overview
An end-to-end Ecommerce analytics project designed to monitor TikTok Shop sales, marketing performance, and operational KPIs through interactive Power BI dashboards.

This project focuses on transforming raw Ecommerce and campaign data into actionable business insights to support decision-making and performance optimization.

---

# 🎯 Business Objectives
- Monitor GMV and revenue performance across Ecommerce channels
- Analyze campaign effectiveness and booking performance
- Track customer purchasing behavior and conversion trends
- Improve operational visibility through centralized dashboards
- Support data-driven business decisions for Ecommerce operations

- Livestream periods generated significantly higher conversion rates

- Automated dashboards improved reporting visibility and reduced manual monitoring efforts
